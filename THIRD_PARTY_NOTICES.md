- Fichier : `extension/lame.min.js` (distribué tel quel, non modifié, chargé comme script séparé)
- Auteur : Alex Zhukov — <https://github.com/zhuker/lamejs>
- Licence : **LGPL-3.0** (texte et conditions du projet : `third_party/lamejs/LICENSE`)
- Basé sur **LAME** (<https://lame.sourceforge.net>), également sous LGPL.

La LGPL-3.0 est compatible avec la GPL-3.0 sous laquelle est publié RF Sampler (le fichier reste, lui, sous LGPL).

Conformément à la LGPL, ce fichier est fourni comme bibliothèque distincte : tu peux le remplacer par une autre
version de lamejs (même API `lamejs.Mp3Encoder`) sans toucher au reste de l'extension. Le code source de lamejs
est disponible à l'adresse ci-dessus.
